**Objective:** Implement Q-Learning to solve the Cliff Walking problem from Sutton & Barto textbook.

**Files:**

- [lab1_cliff_walking_bilingual.md](lab1_cliff_walking_bilingual.md) - Lab instructions (中英对照)

**Key Concepts:**

- Temporal Difference (TD) Learning

- Grid world environments
- Exploration vs Exploitation

**Deliverables:**

- Modified environment code for Cliff Walking
- Q-Learning agent implementation
- Demonstration of working solution
